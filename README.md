# 🛒 E-Commerce Shopping Cart & Checkout Portal

A dynamic, responsive web application featuring an interactive product catalog, real-time shopping cart management, automated price calculation, and a multi-option checkout form.

---

## 📌 Features

* **Interactive Product Catalog:** Browse products with pricing, descriptions, and one-click "Add to Cart" functionality.
* **Real-Time Shopping Cart:** Live cart updates, quantity adjustments, item removal, subtotal tracking, tax/shipping calculation, and total price display.
* **Customer Intake & Checkout Form:** Shipping, billing, and contact details with client-side field validation.
* **Multiple Payment Options:** Flexible checkout supporting Credit/Debit Cards, Digital Wallets (UPI/PayPal), and Cash on Delivery.
* **Responsive UI:** CSS Grid and Flexbox layout optimized for seamless browsing across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for product grids, modal cart overlays, and checkout forms.
* **CSS3:** Custom styling, CSS Grid, Flexbox, responsive design, and UI hover effects.
* **JavaScript (Vanilla ES6):** State management for cart items, dynamic DOM updates, price arithmetic, and form validation logic.

---

## 📋 User Workflow

1. **Browse & Select:** Explore items in the store and add desired products to the shopping cart.
2. **Review Cart:** View selected items, adjust quantities, or remove items while observing live price updates.
3. **Shipping & Billing:** Enter full customer details, delivery address, and contact information.
4. **Payment & Review:** Choose a preferred payment gateway and confirm order details.
5. **Order Confirmation:** Submit the order form to view the completed transaction summary.
